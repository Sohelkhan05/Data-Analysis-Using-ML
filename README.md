# 📊 Data Analysis Using Machine Learning

A beginner-friendly Machine Learning and Data Analysis project developed using **Python**, **NumPy**, **Pandas**, and **Streamlit**. This project is designed to help students understand fundamental programming concepts, data manipulation, and numerical computing through interactive examples.

# Project Overview
This repository contains practical implementations of:

-  Python Basic Programming
-  NumPy Operations
-  Pandas Operations
The project is structured to provide hands-on learning for beginners in Data Analysis and Machine Learning.
